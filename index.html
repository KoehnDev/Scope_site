User Management

Create employees by email, manage access levels, and send secure password resets.

Create User activates the Employee immediately without sending email. The employee must change the temporary password at first sign-in.

New invited users are Employees by default. Admins can promote another user to Admin. Remove User permanently removes login access and transfers that user's projects to the Admin performing the removal so company history is retained. Password reset links are sent to the user's email; temporary passwords require the user to choose a new password at next sign-in.
